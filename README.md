# 🍕 Sistema Ravelle - Administração de Vendas e Produtividade

Este projeto consiste em um sistema administrativo e painel de controle (Dashboard) desenvolvido para a **Pizzaria Ravelle**. O objetivo principal é sanar dores reais do negócio, como a falta de controle de rendimento das vendas e a dificuldade na padronização de informações operacionais.

O sistema funciona como um Produto Mínimo Viável (MVP) focado em digitalizar o processo de gestão, fornecendo relatórios analíticos e controle centralizado para administradores.

## 🚀 Funcionalidades do Sistema

O sistema conta com 5 telas principais totalmente funcionais e responsivas:
* **Autenticação (Login):** Acesso seguro restrito para administradores do sistema.
* **Dashboard de Análise e Estatísticas:** Visão geral da saúde financeira e operacional do negócio, utilizando gráficos dinâmicos.
* **Gestão de Vendas:** Módulo dedicado à análise aprofundada de pedidos e acompanhamento do rendimento em tempo real.
* **Controle de Estoque:** Gerenciamento centralizado de produtos e insumos operacionais com alertas visuais de criticidade.
* **Cadastro de Funcionários:** Registro e controle completo da equipe interna e entregadores.
